# Python + FastAPI desde cero

Una guía paso a paso para armar un backend con **Python** y **FastAPI**, pensada para quien nunca escribió una línea de Python.

Si ya programaste en **Express**, **Django** o **Spring Boot**, vas a encontrar comparaciones escondidas en desplegables: las abrís si te sirven y las ignorás si no.

## Qué vas a construir

Una API completa con:

- Rutas, validación de datos y documentación automática con **FastAPI**.
- Una base de datos **PostgreSQL** manejada con **SQLAlchemy** y migraciones con **Alembic**.
- Todo corriendo en contenedores con **Docker Compose**.
- Registro, login y rutas protegidas con **JWT**.
- Tests con **pytest** y código prolijo con **Ruff**.
